## 3. 迁移条目

- ProductShell 新增 `previewStates?: Readonly<Record<string, string>>`，默认不传。文档用的静态态，按菜单行或分组 id 写 `data-tcrn-preview-state`，原样传给完整菜单与各下拉。
- ShellDropdown 的 `previewStates` 多认一个值 `"open"`：带下一级的行标 `"open"` 时，该级起始即开（从下拉自己的行逐级往下；空格分隔的多值照 CSS `~=` 认）。其余值照旧只写属性。
- ShellDropdown 定位：从装着固定层的祖先（transform、perspective、filter、backdrop-filter、layout / paint 包含、容器）的内边距盒起算，没有这种祖先时与原来一样从视口起算；每次渲染后和顶带尺寸变化时（有 ResizeObserver 时）重读固定项位置。
- `useShellMenuCascade(rootRef, firstLevel, initialOpenPath = [])`：新增可选第三参，作为打开路径的初值。
- 级联键盘：ArrowLeft 从级联列回到打开它的行时，优先渲染出来的那一行。
