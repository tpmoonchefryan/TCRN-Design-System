## 4. 写明的选择与回显项

1. 三条 token 按 C-2 默认名落地：`shell.mark`、`shell.touch`、`shell.crumb-icon`，主题无关，shell 组；tokens.json 里 shell-row-h、shell-srch-h 的 note 与 ui-tokens 描述改为「粗指针下改指 shell.touch」。
2. 粗指针块的形态：`@media (pointer: coarse) { :root { /* tcrn-token-block: pointer-coarse */ … } }`，紧跟主题无关块、在夜间块之前；映射写在 ui-tokens（`tcrnCoarsePointerTokens`），因为 contract-generate 只把 key、cssVar、group、value 写进生成物，而生成器不在本包。`createCssVariables(tokens)` 只在名字与目标都在主题无关块里时输出这一块。
3. `parseTokenCssBlocks` 认一层 `@media` 嵌套并报 `media`；`compareTokenThemeBlocks` 只拿顶层块做 C5 比对，另要求 media 块只改指主题无关名（不得改主题名、不得引入新名）。tokens-sync `--check` 另断言粗指针块紧跟主题无关块（三份：生成器输出、tokens.css、storybook.css）。
4. C10 扫描（shell-fidelity `shellGeometryLiterals`，检查名 `shellGeometryLiteral`）：读 `styles/shell*.css.ts` 的拼接段，几何属性（宽高及 min/max、inset 与四向、gap、padding、margin、flex/flex-basis、grid 轨道、圆角、translate/transform）与壳模块里所有自定义属性中的 px 字面量判红；calc/clamp/min/max 值与 0、1px 沿用现写法放行；字号、outline、边框宽不算几何。自检在门内：196px 的 inline-size、gap+padding、自定义属性与旧的组件层粗指针 `:root` 各判红，calc、1px 细线、字号不判。未新增 package.json 脚本。
5. SUB-155 的 pair 变量名（均为 `--tcrn-pair-*` 局部名，token-extension 认）：`-nav-*`（NavItem）、`-subnav-*`、`-toc-*`、`-tree-edge-*`、`-crumb-*`、`-locale-*`、`-locale-option-*`、`-result-*`。语言触发器的悬停与展开仍写 `:hover` 与 `[aria-expanded="true"]`（(0,2,0)，基础规则在后，靠特异性取胜），保留了 `tests/contract-proof.test.mjs:161` 用作锚点的原文。
