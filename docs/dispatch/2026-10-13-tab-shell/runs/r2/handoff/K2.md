## 4. 写明的选择与回显项（实施侧，可事后更正）

1. SUB-165 取判断的第一种改法：比对副本 = 前缀化的家族段（到 settings 段前）+ settings 覆盖 + 前缀化的壳层段，壳层段排最后，与包内顺序一致；没有做逐条筛规则的第二种。壳层段仍按 `\n.tcrn-shell-brand {` 定位（变量 `shellComponentCss`，全局表与副本共用）。
2. SUB-166 的跳过范围按类名认三种字标载体：`.tcrn-shell-brand__word`（标按钮 b 与 em）、`.tcrn-product-logo__line-one`（锁定块首行）、`.tcrn-brand-wordmark`（BrandWordmark，判断没点名，同属品牌字标，一并纳入）；没有另加文档层专用钩子。台账 `exemptSubtreeSelectors` 同步加这三个类（台账注释要求与运行时跳过对齐；不加的话 zh-CN 扫描会把留英文的「Design System」报成泄漏）。页模板不再给文档壳的 b 加 `data-locale-invariant`。
3. 变更日志的单一来源取 `storybook-locale-text.ts` 的 `group.Change Log`：删掉 `storybook-content-text.ts` 的 "Change Log" 键，运行时改由文档壳自身五语渲染得来的词条换字。连带 ja、ko、fr 的壳内文字由「変更ログ」「변경 로그」「Journal des modifications」变成与页标题一致的「変更履歴」「변경 기록」「Journal des changements」。
4. Esc 的约定：语言列表开着时，i18n 脚本关列表、焦点回触发键并 `preventDefault`；文档壳层脚本见 `defaultPrevented`，或头像菜单里有开着的语言列表，就不处理这次 Esc。列表关着时 Esc 照旧由层脚本关头像菜单或完整菜单。
5. SUB-167 的新类名：`tcrn-doc-shell-demo` → `tcrn-doc-demo-frame`（修饰 `--knowledge`），`tcrn-doc-knowledge-shell__pager` → `tcrn-doc-demo-pager`；其余 `tcrn-doc-knowledge-shell*` 规则与 `--tcrn-knowledge-shell-*` 自定义属性全部删除（含末尾的 brand-cell 段与窄屏块里的三条）。
6. 组件参考页索引格的 `:active` 缩放删除（`--tcrn-motion-press-scale` 无 G+ 后继，G+ 按钮家族按下不缩放），过渡里的 transform 一并去掉；悬停与获焦不变。
