SUB-197：照判据字面「可钉行六个字段都读包装」时，包装读数为 minHeight `auto`、fontSize `13px`、paddingLeft `0px`、paddingRight `4px`，普通行为 `0px`、`12.5px`、`8px`、`4px`，会多出三处差。这三处都是包装与行链接分工造成的：包装的 13px 是从菜单继承的字号，不用来排任何行文字；左内距 8 在行链接上。板 `.ts-it` 是单个元素：padding 0 4 0 8，字号 12.5px。所以行盒读法定为：普通行就用行链接本身；可钉行的四向内距用「包装内距 + 行链接在该侧的内距」计算，只在行链接贴着包装内容边的那几侧相加（左、上、下相加；右侧钉钮夹在中间，只取包装的 4）；fontSize 与 minHeight 仍读行链接，和 R2 一样。字段与精确相等的判定不变。按判据字面读的三处差列为问题 5。
