## 4. 写明的选择（B 类，收口回显）

1. **SUB-188**：保留 `justify-self: center`。盒宽和图标列宽是同一个表达式，所以盒的位置与 `start` 相同，没有写 B2-2 的 `start`。
2. **SUB-182**：
   - 内收环的宽度用 `--tcrn-space-0h` 与 `--tcrn-space-1`（2 与 4），同文件的铃铛小点也是这样用 space token 写环宽的；颜色用 `--tcrn-color-surface` 与 `--tcrn-color-acc`。没有用 `--tcrn-color-focus-ring`，因为它是弃用别名。
   - 纸内滚动区写两条状态规则：一条只切 pair，一条只写强制色描边。
   - 兜底名单加上了纸内滚动区本身，因为它现在有自己的 pair。
   - 探针对纸内滚动区真实调用 `focus()`，再核对 `:focus-visible`，读阴影和描边两者中较大的外扩。区域拿不到 `:focus-visible` 时也记作违例。
3. **SUB-192**：
   - 在判据列出的四个属性之外，基础规则还加了 `display: block`。行内 span 不受 overflow 与 text-overflow 作用，不加的话菜单外不会截断。
   - title 的取字换成新的递归取字（`navItemLabelText`），标签写成标记时也能取到文字。钉钮命名仍用原来的 `navItemText`，保持不变。
4. **SUB-183**：判据 ① 要求保留不存在断言和不使用断言，③ 要求 grep 结果为 0，两条字面上互相冲突。做法是两条断言都不写出变量名，改成更强的形式：
   - 不存在断言写成「壳里唯一的 motion 变量是 `--tcrn-motion-product-shell`，没有任何变体」；
   - 不使用断言写成「任何变体都没有 var() 读取」。
5. **SUB-180**：第三条用例在按 ← 之前先确定目标：上一列中渲染出的、`aria-expanded="true"` 的那一行。按 ← 之后焦点就在这一行上。← 会关掉它离开的那一列，所以按完以后这一行读 `aria-expanded="false"`；这是原有行为，现有的两列用例也断言了这一点，不是缺陷。JSDOM 不做布局，渲染判定用 `getClientRects` 模拟：连在文档上、又不在 `[hidden]` 下就算渲染。ResizeObserver 用测试内的替身，测试结束后还原。
