## 2. 写明的选择与回显（B 类，Owner 可事后更正）

1. **换名只按发布的别名表一对一替换。** @tcrn/ui-tokens 的别名在两个主题块里都是 `--旧: var(--新)`；文档层和包里都没有别处在局部重设新名，所以换名后值不变。核对方法：把 `8f5990c` 的四个文件按同一张表换名，再和 `f41f1d3` 逐字比较。除第 2 条以外完全相同（`logs/r3-m8/24-rename-equivalence.txt`）。
2. **删掉 en/fr 与 zh-CN 的两条字族规则，不换名。** 这两条把 `--tcrn-type-family-ui` 设成 latin、zh-cn 别名，而这两个别名本身就是 UI 栈。按表换名会写成 `--tcrn-type-family-ui: var(--tcrn-type-family-ui)`：自引用，计算值失效，字族退回继承值。规则删掉后，这三种语言直接读 UI 栈，渲染不变；ja、ko 两条不动，原处留一句注释说明。
3. **`doc-class-map.json:39` 只改 reason 一句。** doc-shell:proof 不读条目内容，只报 `unmapped`（实测 `[]`），所以这次不是门要求的改动。改的原因是原句写着「shell-fidelity-proof.mjs registers EX-…」，例外删掉后这句不再成立：改成过去时，并补一句由 SUB-204 删除。disposition 保留 `rename-tcrn-doc`：INIT-015 确实改过名，而且改处置会和 `docs/verification/doc-shell-class/r2-clearance.md` 的处置计数对不上。doc-shell 测试「class map gives every baseline class exactly one allowed disposition」仍过。
4. **删除处的代码注释不写例外编号和类名。** `shell-fidelity-proof.mjs` 在白名单和例外表旁各留一句文字说明。现在 grep 例外编号，代码里是 0 处，只出现在 style-scale 的「Removed」和类映射的历史句里。

   - 「Shell / doc-chrome demos」改为「Shell demos and the documentation page」，只列仍有规则、也有页面写入的类，并注明文档壳就是包的 ProductShell。
