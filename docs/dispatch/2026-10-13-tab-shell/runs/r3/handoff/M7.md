## 4. 写明的选择（B 类，可事后更正）

1. 文档壳的模型以英文 JSON 随页（`script[data-doc-shell-config]`），客户端经页面词典换成读者语言；词典条目改由各语言的模型逐串配对生成，不再对齐各语言的静态渲染。
2. 页面正文在纸内仍是页面自己的静态标记（`[data-doc-page-body]`），React 只渲染一次（memo），换字与各页面脚本照旧处理它，正文里的壳屏块照旧各自水合。
3. 门用接口 `window.tcrnDocShellLayers` 保留，开合同步生效且不移动读者焦点；`setMenu` 多一个门专用选项 `{ presentation: "panel" }`，读者的菜单仍随视口。
4. 窄屏的菜单模型读数在面板上读（smoke 与 browser-proof 的 zh-CN 读数临时调到 1440 再复原；browser-proof 分区页摘要用上一条的选项），与原来在各宽度读隐藏面板的含义相同（问题 5，交判断确认）。
5. 在语言列表里按 Esc 只关列表、焦点回列表触发器，头像菜单保留（沿用 SUB-166 的约定，在 DocShellRoot 里处理，包不动）。
6. 参数名照 C-12 默认 `shell-shortcut=<屏 id>`；壳层门新导出 `SHELL_SHORTCUT_PARAMETER`，shell-hydrate 导出 `shellShortcutParameter`、`shellShortcutScreen`。
