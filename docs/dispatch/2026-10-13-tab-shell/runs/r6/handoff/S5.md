## 3. 做法与选择（回显）

1. **选择器取 `.tcrn-nav-pin:not(:where([aria-pressed="true"]))`。** `:where()` 不计特异性，`:not()` 取参数的特异性，所以整条是 (0,1,0)，与第 476–478 行两个选择器（`:where(…) > .tcrn-nav-pin` 与 `.tcrn-nav-pin:where([aria-pressed="true"], :focus-visible)`）相同，也与图钉基规则 `.tcrn-nav-pin { opacity: 0 }` 相同；它写在基规则之后，同权时后者胜。没用 `.tcrn-nav-pin:not([aria-pressed="true"])`（(0,2,0)，比第 476–478 行重），也没用整条包进 `:where()`（(0,0,0)，压不过基规则的 opacity 0）。
2. **没用 `.tcrn-nav-pin:where(:not([aria-pressed="true"]))`。** 它同样是 (0,1,0)，但 GWT1/GWT4 用例（第 1812–1821 行）把凡以 `.tcrn-nav-pin:where(` 开头的规则当作「只换图钉对」的状态规则逐条核对，opacity 不是对变量会判红。为了不放宽那条旧读法，触摸规则用 `:not(:where(…))` 写法：匹配的元素与权重都一样，旧读法一字不改。
3. **颜色不另写。** 图钉的 `color` 本来就是 `var(--tcrn-pair-pin-ink)`，静止对 `--tcrn-pair-pin-ink-d: var(--tcrn-color-ink-3)`，即颜色取图钉对的现有变量，指向 ink-3 的现有 token。新规则只写 `opacity: 1`，不写颜色、不换对：fill 与 ink 照旧成对由状态规则切换；已固定（acc）、hover（墨洗加 ink-3）、获焦（焦点环）在粗指针下照旧生效。若在这条规则里写 `color`，同权后写会盖住 hover 与已固定的 ink，fill 与 ink 也会拆开。
4. **已固定的图钉不在选择器里。** 它们由第 477 行照旧显示；文档屏的预览 hover 规则（`shell.css.ts` 第 504 行）不动。
5. **jsdom 当细指针用。** jsdom 26.1.0 的 `getComputedStyle` 只套用媒体列表里写了 `screen` 的 `@media` 规则（`style-rules.js` 第 101–102 行），所以 `(pointer: coarse)` 块在 jsdom 里不生效；用例里 jsdom 的读数就是细指针静止态的模型读数。粗指针的计算样式由第 4 节 ④ 的 Chromium 探针量。
