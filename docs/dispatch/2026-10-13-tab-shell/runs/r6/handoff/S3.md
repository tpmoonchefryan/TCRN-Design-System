## 3. 做法与选择（回显）

1. **判方向（组件内部，C-12）。** 已开级联时读第一列（面板）与各级联列的盒子：伸出量 = 各列相对第一列向两侧伸出的最大值（与列当前站在哪一侧无关）。接在右侧时的越界量 `pastEnd = 第一列右缘 + 伸出量 − 视口宽`，接在左侧时的越界量 `pastStart = 伸出量 − 第一列左缘`；`pastEnd > 0` 且 `pastStart < pastEnd` 时为 start，否则为 end。视口宽取 `documentElement.clientWidth`（布局视口、不含滚动条），为 0 时退回 `innerWidth`，仍为 0（无布局）时不转。
2. **选择 a（越界判据多一条）：** 两侧都放不下时保持越界更少的一侧，不把列整列转出左缘（390 视口的读数见第 4 节⑤）。判据原文只说越右缘即转；这一条只在两侧都放不下时起作用。
3. **选择 b（不粘滞）：** 方向随当前已开的列重算。← 关掉第三列后，若第二列接在右侧放得下，会回到右侧（DOM 用例里第二列单独仍越界，所以仍在左侧）。
4. **选择 c（视口）：** 取真实布局视口，不取文档页屏块（`contain: layout` 的块）的右缘。
5. **选择 d（不越界时不写属性）：** 只在判为 start 且有已开级联时写 `data-cascade-side="start"`；end 不落属性，服务端也不写（服务端读不到视口）。所以不越界时根元素的属性与改前逐项相同（DOM 用例断言属性名只有 class、data-shell-dropdown、style），smoke 对服务端根元素 `<div class="tcrn-shell-menu tcrn-shell-dropdown" style="visibility:hidden" data-shell-dropdown="">` 的整段断言不受影响（单测同样断言）。
6. **样式（判据 ②）。** `direction: rtl` 让单行网格从右起排：第一列是显式轨，仍占根盒 `[left, left + drop-w]`，固定项下方位置不变；级联列是隐式轨，依次向左，轨宽仍是 `grid-auto-columns: var(--tcrn-shell-drop-w)`、间距仍是 `column-gap: var(--tcrn-shell-cascade-gap)`（shellCss03 原有），高仍由同一网格行拉伸。面板与列 `direction: ltr`（五种语言都从左到右；未转向时计算值不变，像素检查相同）。两条规则不含颜色、不写长度；特异性 start 规则 (0,2,0) 与变体 `.tcrn-shell-menu.tcrn-shell-dropdown` 相同，ltr 规则 (0,1,0)；`data-cascade-side` 不在 contract-static 的状态属性表里。没有新 token（C-2）。
7. **键盘、Esc、aria-owns（判据 ③）。** 这部分代码未改：← 按 DOM 中的列序回上一列（列序不随方向变），Esc 走 `useShellTransientLayer`，`aria-owns` 仍按已开路径列出列 id。完整菜单（ShellMenu、shellCss03）不改；props 与导出不改。
