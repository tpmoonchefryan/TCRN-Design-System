## 3. 做法与选择（回显）

1. **rf 样片。** `build-inputs.mjs` 第 16 行（原第 15 行之后）加一条 `.in:where([readonly]:focus-visible,.is-ro.is-focus){--edge:var(--edge-rf)}`：只换边，底与字色留 r 的；`--edge-rf` 是 `pairDecls` 从 `pairs.json` 的 rf 写出的值（`inset 0 0 0 1px var(--acc),var(--focus)`，与 f 的边相同），板上原本已声明。第 111 行加 `rofocus: " is-ro is-focus"`；第 112 行让 rofocus 同 ro 一样带 `readonly` 属性（选择：与 readonly 样片同一语义，样片是真的只读框）。第 128 行在 readonly 后加 `["readonly + focus", …]`，不带 `cell`，即不加 `data-cell`。第 174 行块标题「八种状态」改「九种状态」，说明里补「readonly+focus 留只读底换环」（选择；量过标题仍单行 16）。
2. **快捷键色。** 第 27 行 `.sw>kbd` 的 `var(--ink-3)` 改 `var(--ink-2)`。第 180 行 SearchInput 块说明只写「右侧 kbd 快捷键」，没写颜色，不改；E、F 段两处提到快捷键的文字也没写颜色。
3. **底盘 kv（DIFF-3）。** `V2-GPlus.dc.html` 第 300 行 `侧栏 212 … 顶栏 48` 改 `侧栏 220 … 顶栏 52`（无生成器，直接改，C-20 的唯一例外；按拆分问题第 2 条默认，成品 Tokens 板与 `build-tokens.mjs` 不动，`V2-Rejections` 打回记录不改）。字数不变，板高 1640 不变。
4. **pin 两态。** `build-icon.mjs` 从 `data.mjs` 已导出的 `icons` 取 pin 的 `variants`（outline `fill: []`、solid `fill: [0]`），`pinVariant()` 用名册同一路径（`icon("pin")`，即 `icons.json` 的 body，与包内 `icon-paths.generated.ts` 的 pin 逐字相同）给 fill 列出的子元素加 `fill="currentColor"`，其余子元素仍描边。名册块之后新增一个 `.blk`（不是带字母的板段）：「pin · 描边与实心两态」，两块与名册同款的 20 号图块并列，标签 `pin · outline 描边`、`pin · solid 实心`。选择：两态都用名册的 ink-2，只示形不示色（包里固定态是 acc，见目视项）；不加 `data-cell`。
5. **规则例外。** 绘制规则第 120 行「不用填充，不用双线。」后加「例外：pin 的固定态是实心（icons.json 的描边与实心两态，实心只填 pin 身），只此一例。」；第 124 行「填充色块」后加「（pin 固定态的实心是唯一例外）」。两条 li 量过仍单行。
6. **板高的取法。** 用 Playwright 已装的 Chromium（字体照常从网络加载，29 个请求 0 失败）把 `.board` 改成 `height:auto; min-height:800px` 量 `getBoundingClientRect().height`。改前复现：Inputs 6529.06、Icon 4270.11，与已登记的成品高 6530、4271 相符（成品高 = 向上取整），草稿高 6540、4280 = 大于成品高的下一个 10 的倍数（SUB-133 登记的四块都合这条：5836/5840、4271/4280、5216/5220、6530/6540）。按同一取法：Inputs 6596.81 → 成品 6597、草稿 6600；Icon 4419.11 → 成品 4420、草稿 4430。成品画布按 `order` 以 120 间距重排 y。
7. **生成器重生的连带变化。** 两块草稿板重生后，`.gp` 浅色 token 行多出契约里已有的 6 个壳几何 token（`--shell-mark:22px`、`--shell-touch:44px`、`--shell-crumb-icon:11px`、`--shell-chevron:12px`、`--shell-locale-chevron:11px`、`--shell-mark-lg:44px`），成品 Inputs、Icon 随之同样多出；板内不引用它们，渲染不变。Typography、Actions 两块草稿与成品没有重生，仍是旧 token 行（问题 4）。
