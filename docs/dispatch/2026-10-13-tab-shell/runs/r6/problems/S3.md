2. **数据缺口：越界画面与量门读法。** 文档站没有固定项靠右缘、级联越界的画面，Owner 目视看不到向左展开；量门的级联读法只认向右（`scripts/shell-measure-proof.mjs` 第 406–419 行，`col.l − (prev.l + prev.w) = 4`），若加越界画面，读法须同时按 `data-cascade-side` 分方向（start 时 `prev.l − col.r = 4`），否则该画面会判红。两者都不在本包文件集，未做；建议 R7 由主线程决定是否加画面并同步读法（加画面涉及故事与板，按 C-7 需先确认授权）。
3. **观察：390 视口的 drop 屏。** 390 × 844 下 shell-top-band 的两块 drop 屏仍是打开的下拉，但固定项在窄屏不显示（根 `left: -45px`，面板在视口 0–240），第二列 244–484 越过视口右缘 94；左侧同样放不下（会越过左缘 244），按交回第 3 节选择 a 保持在右侧；根元素属性与改前相同，所以位置也与改前相同。窄屏文档是否还要展示打开的下拉，交主线程判断。
4. **观察：文档页上的 Esc。** 文档类目页同时开着多个预览壳层，每个开着的层都在 document 上收 Esc，各自把焦点还给自己的触发项，最后落在另一块屏（ts-search-l）的标按钮上；drop 屏的打开由故事控制，Esc 后仍开着。所以「Esc 全关、焦点回固定项」在文档页上目视会看到不同结果，只能以 DOM 用例为准（已读，见交回第 4 节③）。本包未改 Esc 与打开控制的代码，按代码推断改前即如此（未在改前的构建上实测）。
