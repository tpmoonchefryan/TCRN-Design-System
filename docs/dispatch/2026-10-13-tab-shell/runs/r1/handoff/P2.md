## 4. 写明的选择与回显项

1. pin 两态是一个名册名、两个变体：icons.json 的 pin 带 `variants: { outline: { fill: [] }, solid: { fill: [0] } }`，fill 是以 currentColor 填充的 body 子元素序号；名册计 38。Icon 组件 API 不变：实心态由 CSS 把图钉的第一个子元素填成 currentColor（经 pin 配对变量，状态规则不写颜色）。pin 标为 `new: true`，description 改写为「new 为第一批（G+）与顶带壳批新增」并说明 variants。
2. 链接里不能放按钮，所以可钉的 NavItem 是一行两个兄弟：`<div class="tcrn-nav-item-row" data-navigation-primitive="nav-item-row" data-nav-pinnable="true" [data-selected]>` 里放原来的 `<a class="tcrn-nav-item">` 与 `<button class="tcrn-nav-pin">`。行用自己的配对上色（G+ 名：ink-2 于透明、hover 时 ink 于 3.5% 墨洗、选中时 ink 于 6% 墨洗，选中压过 hover），链接本身在行内不上色，指向图钉时整行仍亮。NavGroup 的标题行不是交互元素，图钉直接放在 `tcrn-nav-group__label` 里，标题文字包进 `tcrn-nav-group__label-text`（单行截断，带 title）。
3. 槽 24 常驻（`var(--tcrn-shell-pinb)`，按 C-2 名表引用，合入 P1a 后生效）；钮 24 × 24、圆角 radius-small、图标 16；显隐只用 opacity：行 hover、行 :focus-within、钮 :focus-visible、aria-pressed=true 时为 1。粗指针下用 `::after` 向四周扩 space-2h，热区 24 → 44。焦点环走配对 edge 变量，另加透明 outline 供强制色。
4. `pinLabel` 是图钉无障碍名里的「项名」，不是整条名字：默认取 NavGroup 的 label、NavItem 的字符串 children（再退到链接的 aria-label）；整条名字由壳文案表五语模板组成（「固定到顶带：{项名}」/「从顶带取下：{项名}」，en 为 Pin to top bar / Unpin from top bar）。
5. NavGroup 新增可选 `locale`（图钉名的语言，与 NavItem 一致）。未给 `onPinnedChange` 时 NavItem 与 NavGroup 的 DOM 与改动前逐字相同。
6. 两块 Icon 板只提交 A 段名册的两行（浅色、夜间各加 pin）。生成器同时会改写板内 token 块（这是改动前就有的漂移，见问题 3），该行保留 HEAD 原样，未随本包提交。Icon 板名册网格 7 列，37 → 38 不增行，板高不变，未动 heights.json。
7. ProductLockup 新增 `firstLine?: "rail" | "lockup"`（导出类型 `ProductLockupFirstLineScale`）；给了就渲染第二版：`<div class="tcrn-brand-lockup tcrn-brand-lockup--line [--line-rail] [--line-serif]" role="img" aria-label="{产品名}" data-lockup="lkr-line|lk-line" data-brand-lockup="line" data-product-id>`，内含 aria-hidden 的彩色标 `svg[data-logo="<productId>"]`（经 TcrnBrandMark，字节即 logos2 彩色文件）与 `<span class="tcrn-brand-lockup__line" aria-hidden="true"><b class="tcrn-brand-lockup__word">{word} <em class="tcrn-brand-lockup__suffix tcrn-brand-wordmark__suffix--<id>">{suffix}</em></b></span>`。首行恒用彩色标，`markVariant` 对它无效。尺度取 Brand 板 E 段：侧栏 22 + 12.5/600（行高 type-line-control 1.2，间距 space-2h），锁定块 44 + 16/600（行高 type-line-ui 20，间距 space-3h，字距 -0.005em）；Einzbern 与 Mana Orchestrate 用衬线整名（13.5 / 18、400）。居中只靠 lockup 规则的 inline-flex + align-items center，首行规则里没有 padding、margin、top、transform、position。E 段侧栏单元的 padding 6/4 与宽 210 属于栏位，不属于锁定块，未带入。第一版与第三版不变；`ShellBrandLockupProps` 改为 `Omit<ProductLockupProps, "firstLine">`。
8. brand-asset-source-proof 只为认识新变体而加一段：对四枚彩色文件，各在两个尺度渲染首行，比对 `svg[data-logo]` 的值与内容字节，结果进 packageChecks（variant `first-line-rail` / `first-line-lockup`）。contract-proof 只改计数，没有加新判定。

## 5. 给下游包的接口约定

- 图钉（SUB-116、SUB-118 消费）：`NavItem` / `NavGroup` 的 `pinned`、`onPinnedChange(pinned)`、`pinLabel` 按 C-6；钮带 `data-pin-button=""`、`aria-pressed`、五语 aria-label。点图钉不触发链接；需要「选中即收」的浮层请按 `[data-pin-button]` 排除，图钉不应收起菜单。
- 测量（P3 壳层门、SUB-135）：NavItem 的 props（含 `data-shell-row` 之类钩子）落在链接上，图钉是链接的兄弟、不是后代；在行内找图钉要以 `.tcrn-nav-item-row`（或 `[data-navigation-primitive="nav-item-row"]`、图钉的父元素）为行。文字盒为 `.tcrn-nav-item__label`；NavItem 不发 `data-guide="prail"` / `data-text="prail"`（见问题 7）。
- 首行（SUB-114 自行实现标按钮，不导入本件；SUB-121、SUB-134 的 story 可直接用）：`<ProductLockup productId="tms" firstLine="rail" />`。第三版整块不发 `data-lockup`。
