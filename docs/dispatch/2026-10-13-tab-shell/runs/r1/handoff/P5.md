## 3. 写明的选择与回显

1. **终点坐标取实际位置（二选一）：** 用标按钮里标的 getBoundingClientRect（`[data-shell-brand] svg[data-logo]`），不用 token 计算；起点同样取登入卡锁定块里的标（卡内第一个 `svg[data-product-mark], svg[data-logo]`）。飞行标按起点盒定位（left、top、width、height，与 getBoundingClientRect 同一物理坐标系），`transform-origin: 0 0`，只做 translate 加 scale，终帧正好落在终点盒（SSR 测试对三组终点断言到 1e-9），所以层卸下时不跳。
2. **实现方式：** Web Animations API（Story 实现说明允许），关键帧只有 transform 与 opacity；样式段 `shellIntroCss01` 不含任何 transition、animation，只管定位与指针。fade、move、rise、max 取 `--tcrn-motion-intro-*`，曲线取 `--tcrn-motion-ease`，运行时从 `@tcrn/ui-tokens` 的 `tcrnTokens` 读（与 `shellPinsMax` 同法），三段之和超过 max 即抛错。
3. **分相：** fade [0, 120] 卡淡出，标留在原处；move [120, 360] 标飞到标按钮；rise [360, 460] 纸升起（opacity 0 → 1、translateY 10 → 0），字标 `b`、示意槽、固定项、右上簇淡入。标按钮的首行容器 `[data-lockup]` 在 [0, 360] 保持 opacity 0，不给标本身设不透明度；360 时飞行标与真标重合，460 层卸下。层根 `data-intro-phase` 依次为 fade、move、rise。
4. **板面不一致的取舍：** C 段 t = 240 帧把纸画成半显，规则框写三段顺序；按规则框做，升起距离取 `--tcrn-space-2h`（10，合半显帧的位移）。见问题 3。
5. **每会话一次：** sessionStorage 项 `tcrn-shell-intro`（导出为 `shellIntroSessionMarker`，prop `sessionMarker` 可改名）。挂载就是「登入成功这一刻」：第一次决定时写标记（reduced-motion 不播时也写），已有标记则播放 0 次；sessionStorage 不可用时不播，因为无法保证每会话一次。决定只做一次，StrictMode 第二次运行 effect 不会读到自己写的标记。
6. **服务端与水合：** 服务端渲染为空；水合挂载（useSyncExternalStore 的服务端快照为 false）也不播、不写标记，以此落实「服务端渲染首屏时顶带直接在终态」。没有 Web Animations、卡上或标按钮上找不到标、盒宽为 0 时也不播。
7. **不挡输入：** 卡外包带 `inert`（不进 Tab 序列、不收点击），层根 `aria-hidden="true"`；fade 期间层根接住指针，move、rise 期间 `pointer-events: none`（`:where()` 规则，特异性 (0,1,0)，不写颜色）。标按钮在层外，动画期间可以直接聚焦（DOM 测试断言）。
8. **aria 文案：** 本件局部表，五语齐。一个 polite 的 `role="status"`，卡淡出后（第 120ms 起）说已登入哪个产品：zh-CN「已登录 {产品}」、en「Signed in to {产品}」、ja「{产品} にサインインしました」、ko「{产品}에 로그인했습니다」、fr「Connecté à {产品}」。zh-CN 用规范词「登录」，板面图注里的「登入」没有进文案。状态随层一起卸下。
9. **收尾：** 中途卸下时，壳上各部件的动画调用 finish()（落到终态），不调用 cancel()；460 正常收尾也一样。`onFinish(played)` 只回调一次。
10. **公开面：** `ShellIntro` 进花名册与 shell 家族（块 `tcrn-shell-intro`）。小写导出 `shellIntroTimeline`、`shellIntroPlan`、`shellIntroSessionMarker`，以及类型 `ShellIntroProps`、`ShellIntroPhase`、`ShellIntroTimeline`、`ShellIntroBox`、`ShellIntroPart`、`ShellIntroStep`；小写导出不进 utility 名册，与 P1a、P1b 的做法相同。

## 4. 与别包的接口约定（给下游包）

- **ShellIntro：** props 为 `productId`、`card`（登入卡原样，含锁定块，标 128）、`shellRef?`（默认整个 document）、`sessionMarker?`、`onFinish?(played)`、`locale?`，其余透传到层根。要与壳在同一次提交里挂载，此时标按钮必须已在 DOM 里。
- **它读的壳钩子（C-5）：** 落点 `[data-shell-brand] svg[data-logo]`；压住到 360 的首行容器 `[data-shell-brand] [data-lockup]`；随 rise 淡入的 `[data-shell-brand] [data-lockup] > b`、`[data-shell-toggle]`、`[data-pins]`、`[data-cluster]`；升起的 `[data-paper]`。P1c（SUB-119）给 ProductShell 的纸与右上簇挂上 `data-paper`、`data-cluster` 之后它们才会被压住；没挂钩子的部件在动画期间照常显示。
- **层的 DOM 钩子：** `[data-shell-intro]` 带 `data-intro-phase="fade|move|rise"`；飞行标 `svg[data-logo=<productId>].tcrn-shell-intro__mark`（彩色，`data-product-mark-variant="color"`）；卡外包 `.tcrn-shell-intro__card[inert]`；层外一个 `role="status"`。
- **SUB-121（story `shell-intro`）与 SUB-137（行为探针）：** 静态 Storybook 页是服务端渲染、没有客户端 React，ShellIntro 在那里按设计不渲染，需要客户端挂载或静态桥（问题 2）。重放方法：清掉 sessionStorage 的 `shellIntroSessionMarker` 再挂载。期望轨迹：首次挂载 1 次、同会话重挂 0 次、reduced-motion 0 次；`document.getAnimations()` 里的属性只有 transform 与 opacity，最晚在 460 结束。
