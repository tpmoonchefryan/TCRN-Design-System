# 问题清单 · P2（INIT-015 R2）

只记不修。同一根因算一条。本包的局部门在 7213a27 上全绿，没有门红；下列四条是判据缺口、文件集外的过时项，以及按单的限制没改的地方。

## 1. SUB-052：生成段仍有 4 条字面字号或行高，需要新增刻度 token（O-6，待裁定）

- 现象：`packages/ui-react/src/styles/generated/typography.scale.ts` 里，除下面 4 条外，字号、行高、字重都已写成 `var(--tcrn-type-*)`：
  - `.tcrn-text.tcrn-text--numeral.tcrn-text--numeral-inline` 的 `font-size:16px`
  - `.tcrn-text.tcrn-text--numeral.tcrn-text--numeral-large` 的 `font-size:44px` 与 `line-height:48px`
  - `.tcrn-text.tcrn-text--mono` 的 `font-size:11.5px`
- 原因：现有 type token 里没有 16px、44px、48px、11.5px 的字号或行高。判据要求「只引用已有 token，不新增几何 token（O-6）」，新增 token 又属 R2 约定第 3 条列的越级改动，所以这 4 条留作字面值。判据「生成段不再有字面字号行高」因此只部分达成。
- 为防止悄悄增减，Typography.test.tsx 有一条测试钉住这 4 条正好是剩下的全部字面值。
- 建议：下次契约修订由 Owner 决定。一种做法是新增 `--tcrn-type-size-numeral-inline`、`--tcrn-type-size-numeral-large`、`--tcrn-type-line-numeral-large`、`--tcrn-type-size-mono`；另一种是把这几处改用现有刻度值，但那会改变视觉。定下之后只需三步：在 typography.json 的 `tokens` 加条目，在对应条目的 `token` 对象点名，在 index.ts 加注册项；生成器不用改。
