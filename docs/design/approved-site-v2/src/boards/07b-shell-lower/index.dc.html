E消费方契约 须提供什么 · 何时用与不用 · 键盘与读屏

产品须提供

  • 菜单模型：分组 → 项 → 子项（三级）→ 子项（四级）；图标名出自名册、路由、五语标签。
  • 固定项存储：每用户每产品，服务端偏好（跨设备）；可固定分组、项或子菜单；上限 6，顺序为固定顺序，可拖排；第 7 项起只在菜单里标记已固定。
  • 搜索提供者：完整菜单搜全站目标；下拉里的搜索只搜该子树；复用 ProductShellSearch。
  • 品牌资产：三版都出自 Logos 板：标（A 段）、侧栏尺度（E 段侧栏）、锁定块（E 段）；产品只传产品键，不传颜色或文案。
  • 产品清单：切换产品在头像菜单里，锁定块不承担。
  • PageHeader 必有：面包屑 + 标题 + 动作；目录与书签在页内独立空间（TocRail、书签栏）。

何时用与不用

  • TMS、AOS、Atelier、DS 文档站都用这一套顶带壳；没有常驻侧栏。
  • 标按钮是桌面端唯一的完整菜单入口；一段即开，没有小面板。
  • 完整菜单与下拉都是临时浮层：选中、Esc、点外部即收；没有收起钮；与键之间留 6px。
  • 固定的二级菜单从顶带纵向下拉；三、四级按点击向右级联，不按悬停。
  • 右下角锁定块只装饰，不可点、不进 Tab 序列。

键盘与读屏

  • ⌘K / Ctrl+K 打开完整菜单并聚焦搜索；Esc 关闭，焦点回标按钮；菜单内 ↑↓ 走项，→ 进入子项列，← 回左列。
  • 标按钮 aria-expanded、aria-haspopup="dialog"；固定的二级菜单同样；浮层 role="dialog" 非模态。
  • 图钉是真按钮，aria-pressed，可见名「固定到顶带：合约」；行获焦时图钉同 hover 出现。
  • 所有可见字符串五语同源；图标钮都有 aria-label。
  • 触摸端：标按钮 ≥ 40，Sheet 行 44，图钉热区 44。
