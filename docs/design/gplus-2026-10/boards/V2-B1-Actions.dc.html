E消费方须提供什么 · 何时用与不用 五件各一句话，外加状态对机制

Button variant primary|secondary|quiet|danger · size sm|md|lg · disabledReason

一句话：一次动作一个按钮；主按钮每屏最多一个，危险按钮只放在裁决位置，用红字不用红底。

  • 须提供：children 文字（可带 Icon）；disabled 时必须给 disabledReason（变成 title 与 sr 文本）；size 的 lg 为本批新增值。
  • 容器：页头动作区、表单页脚、对话框页脚、工具栏；按钮自身单行，容器负责换行策略（C8）。
  • 不用：导航（用 NavItem / Tabs）；切换主题或语言（用壳层专用件）；表格里的行内链接（用 LinkButton quiet）。

IconButton ariaLabel（必填）· iconName | icon · 其余同 Button

一句话：只有图标的方形按钮，必须有可见名字以外的名字。

  • 须提供：ariaLabel；iconName 取名册；可选 children 作可见标签（则不再是方形）。
  • 用：工具栏、表格行尾、关闭与折叠。
  • 不用：唯一的主动作；含义不明的图标（info、settings 之外的隐喻）。

LinkButton href · variant primary|secondary|quiet

一句话：长得像按钮的链接，用于导航到另一页；同一对表，没有 loading 与 disabled。

  • 须提供：href；外链加 external-link 图标与 rel。
  • 不用：触发请求或提交（用 Button）；正文里的链接（用 Text 的 link 样式）。

ClipboardCopyButton text · ariaLabel · locale · *Label 覆盖 · resetDelayMs · onCopyStateChange

一句话：复制一段文本，五种状态在按钮文字里直接说出来，2 秒后回到 idle。

  • 须提供：text 与 ariaLabel；敏感值走 React 版本（不写进 DOM）；静态页用 mountStaticClipboardCopyButton。
  • 外形：默认 secondary sm；行内可用 quiet sm；idle 带 copy 图标，copied 用 check，failed 用 alert-triangle。
  • 不用：作为主按钮；复制整段多行内容时不给反馈文字。

ButtonGroup 新增 · ariaLabel · size · variant secondary|quiet · children Button / IconButton

一句话：把两到五个同类动作连成一条，共用轮廓与分隔；单选用子项 aria-pressed，组只管几何与可及性。

  • 须提供：ariaLabel（role=group 的名字）；子项各自的 label 或 ariaLabel。
  • 容器：工具栏、页头；组内焦点环抬到最上层。
  • 不用：视图页签与导航（用 Tabs / SegmentedNav）；超过五项（用 Select 或 Menu）；混放主按钮。

状态对机制 · 机器可查 C1 · C2

一句话：变体声明七对 fill/ink（--fill-d/h/a/f/x/l/s），状态规则只写 --fill:var(--fill-h) 这类切换，特异性 (0,1,0) 低于变体 (0,2,0)。

  • 静态检查：任何 :hover、:active、[aria-pressed] 规则里不得出现颜色字面量或颜色 token。
  • 夜间主题只改 .night 下的 token 值，变体与状态规则一字不动（C5）。
