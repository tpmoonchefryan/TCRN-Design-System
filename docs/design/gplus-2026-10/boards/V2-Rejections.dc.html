一、本轮三处缺陷2026-10-10 · v2 画板

现象机理（代码层）我为什么犯（过程层）焕新规则进契约的条款
1 · 悬停填充吞掉文字
B 状态对		 Motion 板里 .I .btn:hover{background:var(--sel)} 的特异性高于 .btn.pri，悬停时主按钮底色被换成 6% 白，字色仍是 --pri-ink 深色，于是深字压深底。状态规则写在基类上，覆盖了变体的「底色 + 字色」配对，却只改了一边。 Motion 板用了精简版 CSS，补了方向级悬停，没有带上变体例外；没有把 variant × state 当作一张表来写；画板没有渲染核对。同一问题在 Button 板上是对的，说明不是不懂，是复制时丢了。 底色与字色永远成对定义为一个 token 对，任何状态只能整体换对；状态选择器的特异性不得高于变体选择器；每个组件的 variant × state 矩阵静态列全，缺格即红。 C1 态对比度矩阵；C2 状态规则不得越级。
2 · 抽屉页脚超出容器
C 几何		 Overlay 板的抽屉用 top / bottom 绝对定位，固定高 276px；内容实际约 300px；页脚 margin-top:auto 被推到容器之外，而容器 overflow:visible。 舞台高度 300px 是目测定的，没有算内容高度；把「页脚贴底」写成 margin-top:auto，却没给容器最小高度或滚动策略；没有渲染核对。这与 2026-08-22 INC-015 品牌锁定块挤扁、INC-399 嵌套卡放不下是同一类。 固定高容器必须声明溢出策略（滚动或裁切）或由内容定高；组件声明自己的最小高度；布局不靠目测，交付前用 DOM 量；overflow:hidden 不得用来藏可操作控件。 C3 不溢出；C4 固定高容器声明溢出策略。
3a · 暗色选中态 AI 味且与浅色分叉
D 分叉E 套路		 I 方向选中项 = 6% 白底 + 左侧 2px 青线（inset box-shadow），浅色方向选中 = 实白药丸。左边条正是 craft 明禁的「带彩色左边条的卡片」，也违反 INIT-013「着墨」裁定：选中接管既有结构，绝不填充与边线兼有。 暗色选中态是单独设计的，没有从浅色的同一规则派生；伸手拿了后台工具最高频的套路。契约里「theme-specific behavior forks」早已是禁项，我没有对照。 选中、悬停、焦点在所有主题里是同一机制、同一属性集，只有值不同；选中只允许一种结构变化（底色、字重或面升起，三选一）；禁止左侧色条与单侧内阴影。 C5 主题属性集同构；C6 选中态结构规则。
3b · 面包屑被压成两行
C 几何J 截断		 Navigation 板右栏只有 492px，顶栏内容最小宽度约 540px（面包屑 + 搜索 260 + 铃铛 + 头像）；面包屑 flex 项可收缩，中文可在任意字间折行，于是每段折成两行。 没有为较窄的栏目做宽度预算；没有声明工具栏里哪个项让步、哪个项固定；中文没有 nowrap 的天然保护，我按拉丁文的直觉写了。 工具栏类行必须声明唯一让步项（通常是搜索框，带 min-width）与固定项（flex-shrink 0）；面包屑、导航项、按钮、徽标、表格单元、页头标题一律单行，装不下截断加 title，不折行（Owner 2026-08-22 案④裁定）。 C7 单行元素不折行；C8 工具栏让步声明。
4 · G+ 页面样例混乱
C 几何G 门盲		 噪点层 .grain{position:absolute} 写在前面，后面的通配规则 .scr > *{position:relative} 同特异性覆盖了它；SVG 变成网格项占了第一格，侧栏被推到宽列，内容掉到第二行，表格被裁掉。 用通配子选择器改定位，没想到它会盖掉前面的绝对定位；仍然没有渲染核对就发布。修复后在浏览器里量过：侧栏 212、内容 998、无元素超出外壳，并截图核对。 定位规则只写在具体类上，不用通配子选择器；任何画板发布前经过一次真实渲染加 DOM 测量，从本板起执行。 C3 不溢出；C14 增补：画板与样例的渲染核对是交付条件，不是可选项。
5 · 悬浮的白色侧栏与顶栏突兀
E 套路D 表面模型		 侧栏与顶栏做成 78% 白玻璃的独立卡片，静态页面里它们下面没有内容可透，于是读成两块贴在画布上的白卡；内容区反而直接铺在画布上，表面层级倒置。 把「玻璃壳层」当成视觉特征来展示，而不是当成滚动时才出现的行为；没有先定表面模型（画布、纸、玻璃各是什么）就画。 表面模型先定：壳层是画布色，靠发丝线分区；内容是一张白纸；玻璃只给轻提示、弹层与内容滚过时的顶栏。深浅两套同一模型。 C11 禁用清单增补：无内容可透的玻璃壳层；C5 表面模型在两套主题下同构。
6 · 侧栏引导列没有一条左线
C 几何G 关系		 品牌标左 16、导航图标左 17、分组标题左 17、头像左 14，文字起点 41 / 47 / 46；每一行各自用 flex 加不同内距，没有共享的引导列。 逐行写样式，没有把「引导列宽 + 左边 + 文字起点」当作一组关系来定义；这正是 INC-022 第二轮退回的「关系差」类缺陷，属性值各自合法而排不齐。 侧栏所有行共用一个 22px 引导列：左边 16，文字起点 48，分组标题同 16；修后用 DOM 量过两屏全部 16 / 48。 C17 新增：壳层与列表的引导列、文字起点、右缘为关系断言，量两侧实际元素，不比属性清单。

三、十类根因与它们为什么反复发生

A规格留白即兴补画

为什么会犯：空白不会报错，「合理发挥」比停下便宜；凡是钉到字节、数值或行号的都做对了，凡是留给执行者的都得到即兴产物。

纪律：资产钉字节、规格钉数值、空白即停（MIN-089）。

B状态与对比度没有成对定义

为什么会犯：状态写在基类，变体后补；对比度只算默认态；悬停、焦点、下划线各自单改一边。

纪律：fill 与 ink 成对 token；全态矩阵；每态算对比度。

C几何没人量

为什么会犯：目测与缩小截图代替测量；「看起来正常」；几何门从未红过就上线。

纪律：DOM 测量；每道几何门先红一次；固定高容器声明溢出；单行元素 nowrap。

D主题、样例、文档、包分叉

为什么会犯：复制比引用快；分叉不报错；暗色单独设计；demo 层与包同前缀。

纪律：一处真相在包；样例只用注册组件；主题只换值不换属性集；私有类改前缀。

E套路化与 AI 味

为什么会犯：高频模式是默认输出，没有禁用清单对照；左边条、渐变六边形、云阴影、卡套卡、四层语义一种外形都是这样来的。

纪律：禁用清单进契约，机器扫描 CSS 特征。

F控件语义错配

为什么会犯：先找最近的东西用上；没有「这个位置该用哪个组件」的表。

纪律：壳层元素先在 Storybook 找专用件；值域决定控件（resolveFieldValueControl）。

G门看不见

为什么会犯：属性清单抓不到关系与存在性；断言只在 en 下评估；覆盖面由执行者事先决定；三连绿不排除 50% 失败率。

纪律：元素清点差集、关系比对、红绿两侧可达、先红再绿。

H文案与本地化退化

为什么会犯：属性里的文案不进翻译树；修样式时顺手烤死英文。

纪律：所有可见字符串含属性五语言同源（INC-023 已有门）。

I密度与节奏

为什么会犯：把 13px / 36px 当默认值放松；排版节奏没有 token。

纪律：密度不放松；节奏差在容差内（shell:parity 已有）。

J截断与折行

为什么会犯：折行是浏览器默认，中文尤其；用 overflow:hidden 把溢出换成半个字。

纪律：一行不折、装不下截断加 title；收起态明确隐藏或容器按内容定宽。

四、写入机器消费契约的条款草案每条含机器检查与先红要求

编号约束机器检查先红要求
C1每个组件的 variant × {default, hover, active, focus, disabled, loading, selected} 都有成对的 fill 与 ink，文字对比 ≥ 4.5，图标与边线 ≥ 3。从包 CSS 渲染每一格，取计算样式算对比度；矩阵缺格即红。注入「hover 改底不改字」变异必须红。
C2状态选择器的特异性不得高于其变体选择器；基类上的状态规则不得改变底色。静态解析 CSS，比较 .x:hover 与 .x.variant 的特异性。注入 .scope .btn:hover{background} 必须红。
C3任何元素的包围盒不得超出最近裁切祖先；浮层、抽屉、轻提示、表格单元、收起态锁定块全部纳入。现有 overflow-leak 检查扩展到 overlay 角色与收起态。把抽屉内容加高 40px 必须红。
C4固定高度容器必须声明 overflow 行为；overflow:hidden 不得裁掉可操作控件或文案。遍历固定高容器，断言其内可交互元素与文案块 clientWidth ≥ scrollWidth 且可见。把页脚推出容器必须红。
C5浅色与深色下同一选择器的声明属性集合相同，只允许值不同；选中、悬停、焦点三态尤其。解析两套主题规则，diff 属性名集合，非空即红。给暗色选中态单加 inset 阴影必须红。
C6选中元素不得同时具备非透明填充与单侧边线或单侧内阴影；禁止 border-left 与 inset x 偏移作为选中指示。扫描 [aria-current]、[aria-selected]、.on 的计算样式。注入左侧 2px 色条必须红。
C7声明为单行的角色（面包屑项、导航项、按钮、标签、徽标、表格单元、页头标题）渲染高度不超过一个行高；装不下截断加 title，不折行。容器矩阵（390 到 1440）下量 clientHeight ≤ line-height × 1.2。缩窄容器必须出省略号而不是换行。
C8每个工具栏声明唯一让步项（带 min-width）与固定项（flex-shrink 0）。矩阵下无换行、无溢出；让步项达到 min-width 后其余不得被压。去掉 flex-shrink 0 必须红。
C9品牌资产只复制不重绘，sha256 逐字节一致。digest 对照（INIT-036 已有）。替换一个字节必须红。
C10壳层几何（侧栏宽、顶栏高、内缩、行高、圆角、间距）逐值来自 token，字面量即红。现有 radius / spacing 字面量扫描扩到几何属性。写入 196px 必须红。
C11禁用清单：左侧色条选中、装饰渐变与光斑、模糊云阴影、卡套卡、四级语义同形、通用件拼壳、表情符号做图标。CSS 特征扫描（shell-fidelity 已有三项）加元素清点与嵌套深度。每项各一条变异必须红。
C12位置到组件的选型表：主题切换、语言菜单、搜索、数值、二值、多值、集合、导航各有唯一组件。selection-grammar 与 resolveFieldValueControl 已有，扩到壳层控件。用原生 select 当语言菜单必须红。
C13一处真相：样例与文档只用注册组件；story 渲染出的 tcrn-* 类必须存在于包 CSS；文档站私有类改用 tcrn-doc- 前缀。类名差集（上一轮已算出 149 个包外类）。新增一个包外 tcrn- 类必须红。
C14每道新门附带一条会红的注入变异；三连绿不作为证据。门自带变异用例并在 CI 跑。门本身。
C15所有用户可见字符串含属性五语言同源。string-source 检查（INC-023 已有）。烤死一个英文 aria-label 必须红。
C16徽标与标签一行不折；收起态明确隐藏文案或容器按内容定宽；禁止用 overflow:hidden 藏字。文案块 clientWidth ≥ scrollWidth 或明确 hidden。把收起态容器压到 52px 必须红。
