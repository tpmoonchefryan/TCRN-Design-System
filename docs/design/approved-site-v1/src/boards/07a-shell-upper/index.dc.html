C登入动画 登入卡上是通过稿锁定块（标 128），收敛为顶带的第二版（标 22）；只用 transform 与 opacity

t = 0 · 登入成功，登入卡上是第三版（标 128）
t = 120 · 表单淡出 --t-fill 120ms
t = 240 · 标飞向左上 --t-move 240ms --ease
t = 360 · 纸升起；字标首行、固定项、右上簇淡入
t = 460 · 终态 = A1：第二版（标 22 + TCRN TMS）

播放条件

  • 只在登入成功这一刻播一次；刷新、会话恢复、SSO 回跳、切换产品都不播。
  • 一个会话内不重复；服务端渲染首屏时顶带直接在终态。
  • 总时长 460ms：120 淡出 + 240 位移 + 100 纸升起与字标淡入，上限 700。

实现约束

  • 只用 transform 与 opacity；登入卡上的锁定块与顶带的首行共用同一份标 SVG（128 → 22），描述行淡出、字标保留。
  • 终点坐标就是顶带标的几何，结束后无跳变；标全程彩色。
  • 动画期间不挡交互：120ms 后指针事件穿透，键盘可直接 Tab 到标按钮。

减少动画偏好

  • prefers-reduced-motion: reduce 时不播，直接呈现终态。
  • 菜单开合、下拉、级联、图钉出现同样尊重该偏好：时长归零。
  • 门：带偏好的渲染里 transition 时长读数为 0，动画次数计数为 0。
