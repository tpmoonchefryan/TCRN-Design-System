E消费方须提供什么 · 何时用与不用 十一件各一句话，外加两条机制

Input · Textarea 原生属性 · disabledReason

一句话：单行与多行文本，一张纸上的一格；禁用时必须说明原因。

  • 须提供：label（同页 for/id 或 aria-label）；disabled 时给 disabledReason；错误时 aria-invalid 加 aria-describedby 指向错误文案。
  • 容器：Field（第五批）或表单网格定宽；控件自身 width 100%。
  • 不用：搜索（用 SearchInput）；数值（用 NumberInput）；封闭集合（用 Select）。

SearchInput shortcut auto|string|false · fill

一句话：找东西的工具，不是表单字段：墨洗无边框，右侧快捷键，focus 回到纸底。

  • 须提供：aria-label 或可见 label；shortcut="auto" 显示 Ctrl K / ⌘K 并写 aria-keyshortcuts；fill 撑满容器。
  • 用：菜单面板与下拉顶部、列表上方过滤、命令面板入口。
  • 不用：收集要提交的值；替代 Select 的筛选。

SuggestInput suggestions · 其余同 Input

一句话：开放字符串加建议，建议不限制输入（data-choice-value-mode=open）。

  • 须提供：suggestions 字符串数组（自动去重）。
  • 不用：封闭值域（用 Select / MultiSelect）。

Select options[{value,label,disabled}] · disabledReason

一句话：封闭单值，原生 select；超过两项或二值放不下时由 SettingChoice 落到它。

  • 须提供：options；首项若是占位须 disabled。
  • 不用：导航与语言菜单（用壳层专用件）；多值（用 MultiSelect）。

MultiSelect options · value/defaultValue · onChange · presentation native|dropdown|checkboxes · emptySelectionLabel · clearSelectionLabel

一句话：封闭集合多选；dropdown 是常规呈现，关闭时摘要选中项，打开时 body 边界的 listbox。

  • 须提供：options；dropdown 给 emptySelectionLabel；checkboxes 给 clearSelectionLabel；必填清单至少一个可选项被选。
  • 静态页：mountStaticMultiSelect。
  • 不用：开放集合（resolveFieldValueControl 判为 unsupported）。

NumberInput min · max · step · inputMode · disabledReason

一句话：数值就用数值控件：原生 number，键盘、粘贴、范围校验都保留；Stepper 只表达流程位置。

  • 须提供：label 与单位（单位写在 label 或 hint）；范围用 min/max。
  • 外形：隐藏原生 spin 按钮，min-width 12ch，tabular 数字。

DatePicker value ISO · min · max

一句话：原生 date，值永远是 YYYY-MM-DD，显示格式随读者的系统。

  • 须提供：label；范围 min/max。
  • 外形：右侧 calendar 图标 14 三级墨；原生指示器透明覆盖同一 30px 区域，点击打开系统日历。

Checkbox 原生属性 · disabledReason

一句话：16 方的原生 checkbox 去掉系统外观：青底白勾、半选横杠、红边错误。

  • 须提供：label（包裹或 for）；描述放 label 内第二行。
  • 不用：二值设置的开关语义（用 Switch）；单选（用 RadioGroup）。

RadioGroup legend（必填）· name（必填）· options[{value,label,description,disabled,minInlineSize}] · value/defaultValue · onChange

一句话：fieldset 加 legend 的原生单选组，看见全部选项就是它的意义。

  • 须提供：legend 与 name（同页两组同名会合并）。
  • 不用：超过五项（用 Select）；导航（用 SegmentedNav）。

Switch label（必填）· description · controlClassName

一句话：立即生效的二值设置；轨 34 × 20，钮行程 14。

  • 须提供：label；需要说明时 description（自动 aria-describedby）。
  • 不用：需要「保存」才生效的选项（用 Checkbox）；多于二值（用 RadioGroup / Select）。

状态对机制 C1 · C2 · C5

一句话：文本类一张对表（d/h/f/r/x/e/ef），勾选类加 mark 色成三元组，开关类是轨、轨边、钮、钮边四元组；状态只切换，不写颜色。

  • 夜间：只改 .night 下的 token，所有 .in / .ck / .tg 规则不动。
  • 轮廓 line-ctl 47% 同 Actions 板（Owner 2026-10-11 定）。

值域决定控件 resolveFieldValueControl

一句话：封闭单值 → Select（或二值 radio）；封闭集合 → MultiSelect；开放单值 → SuggestInput；开放集合 → 不支持。

  • 表随家族重写，机器判定不变。
