E消费方须提供什么 · 何时用与不用 每件一句话摘要在前

Heading level 1–4 · visualLevel 1–4

一句话：标签级别由 level 定，外观由 visualLevel 定，1 至 3 级衬线 400、4 级怪诞体 600，一律单行截断。

  • 须提供：文本 children；level（默认 2）；需要和文档结构不同的外观时给 visualLevel。
  • 容器：由页头、区段、卡片提供宽度；标题自己不折行，装不下截断加 title（C7）。
  • 用：页标题 h1/2、区段 h3、卡片与设置行 h4。
  • 不用：表头与指标标签（用 caps 样式）；按钮与导航项文字。

Text size body | reading | meta | caption · tone default | strong · variant numeral | caps

一句话：段落文本，13/20 次墨为默认；强调只加字重不换色，说明文字用三级墨。

  • 须提供：children；可选 size、tone、variant（现包只有一个 Text 类；三个 prop 为本批新增，Owner 2026-10-11 定，默认值不变）。
  • 容器：可折行，由父级定宽；表格单元内不用 Text，用单元自身样式。
  • 用：说明、帮助、空状态、通知正文。
  • 不用：标题、标签、编号。

Highlight text · query · caseSensitive · markClassName

一句话：把 query 在 text 里的命中包成 mark，只加 8% 青洗底；字重、字距、字号、内距全部不变，命中前后的排版与未命中时逐像素相同。

  • 须提供：text 字符串与 query；query 为空时原样输出。
  • 容器：行内；在选中行与表格单元里同一规则，不另配色。
  • 用：搜索结果、过滤命中、命令面板。
  • 不用：强调语气（用 strong）；状态（用点加字）。

numeral 新样式 · Text 的 variant 值（已定）

一句话：数字用 Source Serif 4 300 等宽数字，单位进 small 槽缩小拉距；只给指标与金额。

  • 须提供：数值文本；单位放在 unit 槽；行内用 inl（16/20 400）。
  • 用：指标、金额、席位、计数。
  • 不用：编号与时间（mono）、表格里的普通数字（正文）。

caps 新样式 · Text 的 variant 值（已定）

一句话：11/16 500、字距 .14em、三级墨；区段编号前缀用等宽。

  • 须提供：短标签文本；可选编号前缀。
  • 用：区段标题、表头、指标标签、页头副标。
  • 不用：可点击元素的文字；超过四个词的句子。

mono 编号 · 现有 --tcrn-type-family-mono 换字体

一句话：IBM Plex Mono 11.5/16 次墨，只给机器可读的值。

  • 用：ID、邮箱、时间戳、快捷键、哈希。
  • 不用：任何给人读的句子。
