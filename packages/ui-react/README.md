# @tcrn/ui-react

Version `4.0.0` is prepared as a local package candidate; the design source is published Sites version 2, commit `e76b7272d98c0359a57c42d49bf70d64e5b4c2ad`.
The current visual documentation consumes `@tcrn/ui-react/approved`: only the explicitly published Sites v2 families and top-band shell. Other root exports remain engineering APIs and are not automatically a Storybook design catalogue. The current stylesheet contains the published families and their scoped shell roles; retired full-family styles and the retired navigation stylesheet are not emitted.

Brand rendering requires one of four registered product keys: `tms`, `einzbern`, `mana-orchestrate`, `design-system`. The SVG geometry, mono and tile renditions and all five taglines are extracted from the real published Brand board. There is no default mother image, free suffix/URL fallback or implied AOS identity. Consumers that previously used these removed inputs must wait for an actually published product asset rather than fabricate a replacement.

The package candidate is 4.0.0; the design source is Sites version 2, commit `e76b7272d98c0359a57c42d49bf70d64e5b4c2ad`. The source contains the adopted K1/K5/C01 amendments. Machine verification and Owner visual acceptance are distinct. See [source and generation order](../../docs/design/README.md).
